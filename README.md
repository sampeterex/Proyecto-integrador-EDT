# USO DE IA
  
  <========>

Durante el desarrollo del proyecto se utilizarán asistentes de inteligencia artificial, como ChatGPT, Claude, Copilot, y Gemini. únicamente como apoyo para:

- Resolver dudas sobre programación.
- Comprender conceptos técnicos.
- Obtener sugerencias de implementación de funcionalidades.
- Mejorar la documentación.

Todo el código generado o sugerido por la IA será revisado, probado y adaptado por los integrantes del equipo antes de incorporarlo al proyecto.
