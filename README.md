# Objetivos del Sistema de gestion de la biblioteca universitaria

OBJETIVO GENERAL

Crear un sistema que ayude a organizar mejor la biblioteca de una universidad, y así sea más fácil manejar los usuarios, los libros que hay y los préstamos que se hacen,
para que todo funcione de forma más rápida y ordenada tanto como para los estudiantes, los profesores y bibliotecarios.

OBJETIVOS ESPESIFICOS

   1. Crear una parte en el código donde se puedan registrar los usuarios (estudiantes, profesores y bibliotecarios),
      para que cada uno tenga su propio usuario y pueda entrar al sistema según lo que le corresponda hacer.

   2. Hacer una parte donde se guarde la información (base de datos) donde se guarde la información de los libros, para poder ver fácilmente qué libros hay, cuáles
      están disponibles y en qué parte de la biblioteca están.

   3. Automatizar los préstamos y las devoluciones de los libros, para que el sistema avise cuando se acerque la fecha de entrega y calcule automáticamente si hay que
      pagar una multa por atraso, evitando así que esto se tenga que hacer a mano.
