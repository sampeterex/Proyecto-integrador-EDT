# Sistema de gestión de la biblioteca universitaria

 # Descripción del proyecto

 Este proyecto consiste en el desarrollo de un sistema de gestión para una biblioteca universitaria utilizando estructuras de datos como arreglos, matrices, listas enlazadas, pilas, colas y árboles. El objetivo es organizar el inventario de libros, administrar préstamos y devoluciones, gestionar listas de espera y facilitar la búsqueda eficiente de información.

 # Alcance del proyecto

 El sistema permitirá registrar libros, organizarlos en estanterías representadas mediante matrices, mantener un historial de préstamos, gestionar devoluciones recientes, administrar solicitudes pendientes y realizar búsquedas eficientes por código o título.

 El alcance se limita a la implementación de las estructuras de datos y sus operaciones principales, así como a la documentación del proyecto en GitHub mediante un repositorio colaborativo y un archivo README.md bien estructurado.
